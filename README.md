# AI Модератор за TikTok LIVE

Android приложение, което чете чата на твоя лайв и с помощта на AI маркира:
обиди, заплахи, омраза, сексуални коментари, спам/реклама и ботове.
При опасност вибрира и показва известие, а **ти** решаваш дали да заглушиш или блокираш.
Приложението не трие и не блокира нищо.

Може и да **поздравява новите зрители** (по желание).

## Откъде чете чата (Настройки → „Откъде да чете чата“)

**По username (по подразбиране)** – като в Welcome Bot:
1. В раздел **Лайв** пишеш своя username → **Свържи**.
2. Приложението отваря `tiktok.com/@username/live` във вграден браузър и чете чата оттам.
   TikTok не трябва да е на екрана. Докато следи, има постоянно известие „AI Модератор следи лайва“.
3. За автоматични поздрави: **Вход в TikTok** в същия браузър (влизаш веднъж, с имейл/телефон и парола).
4. Ако не чете: **Диагностика** → **Копирай диагностиката** → прати ми я.

**Екранът на TikTok** – чете от отвореното приложение TikTok чрез достъпност (раздел Чат → „Проверка“).

## Как работи

1. **Четене** – по username (вграден браузър) или от екрана на TikTok (достъпност). Без пароли в кода.
2. **Бърз филтър** – веднага хваща очевидното: обидни думи (бг, шльокавица, англ., турски), връзки, телефони, „follow for follow“.
3. **Правила за ботове** – едно и също съобщение 3+ пъти, флууд, еднакво съобщение от 3+ акаунта (нападение), имена като `user12345678`.
4. **AI (Google Gemini)** – на всеки ~6 сек. проверява новите съобщения на пакет. Потвърждава или отменя решението на филтъра.
   Без ключ, без интернет или при изчерпан лимит работи само филтърът.

Цветове в Чат: зелено = наред, жълто = спам/провери, оранжево = обида/бот, червено = сериозно.

## Поздрави

Раздел **Поздрави** → Режим:

| Режим | Какво прави |
|---|---|
| Изключено | Нищо |
| Предложение | Готов поздрав в известие и в приложението, натискаш „Копирай“ и го пращаш ти |
| Автоматично | Пише поздрава в полето за коментар на TikTok и натиска „Изпрати“ |

- Поздравява при **влизане** и/или при **първо съобщение**.
- Събира няколко имена в едно съобщение: „Добре дошли, Иван, Мария и Али! 👋“
- Най-често на всеки 30–180 сек. (по подразбиране 45). Под 30 сек. не може – TikTok може да го сметне за спам.
- Не поздравява маркирани, имена като на бот и теб самия (впиши името си в Настройки → Хора).
- Всеки се поздравява по веднъж на лайв. „Нов лайв“ нулира списъка.
- Шаблони: по един на ред, `{name}` се заменя с имената. Може и AI да ги пише в стил по твой избор.
- Ако в момента пишеш нещо в чата, не го пипа – поздравът става само предложение.

⚠ В режим „Автоматично“ приложението пише от твоя акаунт. Дръж интервала разумен (45+ сек.).

## Инсталиране

1. Отвори папката `AIModerator` в Android Studio → изчакай Gradle sync.
2. Run ▶ на телефона.
3. В приложението: **Включи достъпа** → Достъпност → Изтеглени/Инсталирани приложения → „AI Модератор – чете чата“ → Вкл.
   - На Android 13+, ако е сиво: Настройки → Приложения → AI Модератор → ⋮ → „Разрешаване на ограничени настройки“, после пак.
4. Разреши известията.

## APK от GitHub (без Android Studio)

Всяко качване в `main` се компилира автоматично и излиза като **Release** с APK за изтегляне.

1. github.com → **New repository** → име `AIModerator` → Create.
2. **Add file → Upload files** → разархивирай ZIP-а и провлачи **съдържанието на папката AIModerator**
   (`app`, `gradle`, `.github`, `gradlew`, `build.gradle.kts`…), не самия ZIP. Без папката `.github` компилация няма.
   (Или от Android Studio: Git → GitHub → Share Project on GitHub.)
3. **Commit changes** → раздел **Actions** → „Build APK“ (около 5 мин.).
4. Готово: вдясно **Releases** → `AIModerator-1.0.N.apk` → изтегли на телефона и инсталирай.

Ако Actions стане червено – отвори го, копирай грешката и ми я прати.

### Постоянен ключ за подписване (препоръчително, веднъж)

Без него всяка компилация се подписва с различен временен ключ и новата версия **не се инсталира върху старата**
(трябва първо да изтриеш старата). С него обновяваш нормално.

1. В PowerShell (с JDK-то на Android Studio):
   ```
   & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore rado.jks -keyalg RSA -keysize 2048 -validity 10000 -alias rado
   ```
   Запомни паролата. Пази `rado.jks` – **не го качвай в GitHub**.
2. Превърни го в текст и го копирай:
   ```
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("rado.jks")) | Set-Clipboard
   ```
3. В репото: **Settings → Secrets and variables → Actions → New repository secret**, четири пъти:
   - `KEYSTORE_BASE64` – постави копираното
   - `KEYSTORE_PASSWORD` – паролата
   - `KEY_ALIAS` – `rado`
   - `KEY_PASSWORD` – паролата (същата, ако не си дал друга)
4. Actions → Build APK → **Run workflow**.

## AI ключ (безплатен)

1. https://aistudio.google.com/app/apikey → **Create API key**.
2. Настройки → AI → постави ключа. Модел по подразбиране: `gemini-3.5-flash-lite`.

Безплатното ниво има лимит на заявки в минута и на ден. Приложението праща най-много ~10 заявки в минута
и само когато има нови съобщения. При лимит изчаква 1 мин. и междувременно работи филтърът.

Поверителност: текстът на коментарите отива към Google. На безплатното ниво Google може да го ползва за подобряване на услугите си.

## Употреба на лайв

1. Отвори приложението → **Старт**.
2. Пусни лайва си в TikTok (или отвори лайва си от втори телефон като зрител – работи и така).
3. При сигнал: виж кой е → в TikTok натисни името му в чата → **Заглуши** или **Блокирай**.
4. Бутони при сигнал: **Грешка** (не е проблем), **Доверен** (никога не го маркирай), **Скрий**, **Копирай името**.
5. Ако някой пише, че иска да си навреди („Нужда от помощ“), отговори му спокойно и го насочи към близък човек или 112.

## Пробване без лайв

Настройки → **Тест с примерни коментари**.

## Ако чатът не се чете

TikTok често сменя екрана си. Настройки → включи **„Покажи суровите редове“**, отвори лайва
и виж в раздел Чат какво се прочита. Прати ми тези редове и ще оправя `ChatParser.kt`.

## Структура

| Файл | Какво е |
|---|---|
| `LiveWeb.kt` | Режим „По username“: вграден браузър + JavaScript, който чете чата и пише поздрави |
| `KeepAliveService.kt` | Държи четенето живо, докато си в TikTok |
| `ChatReaderService.kt` | Режим „Екранът на TikTok“: чете екрана, пише поздрави (само в режим Автоматично) |
| `ChatParser.kt` | Намира чата и вади „име → съобщение“ и „X се присъедини“ |
| `LocalFilter.kt` | Бързият офлайн филтър и речникът |
| `BotDetector.kt` | Правилата за ботове и спам |
| `GeminiModerator.kt` | Връзката с Gemini (без външни библиотеки) |
| `Greeter.kt` | Кого и кога да поздрави, шаблони |
| `ModerationEngine.kt` | Обединява всичко – без Android, тества се на компютър |
| `ModRepository.kt` | Настройки, таймери, AI на пакети, известия |
| `Alerts.kt` | Вибрация, звук, известия, „Копирай“ |
| `MainActivity.kt` | Екранът (Jetpack Compose, светла тема) |

Тестове: `app/src/test/.../ModeratorTest.kt` (10 теста за филтъра, ботовете, AI отговорите, поздравите).
